How it works

🧑‍🤝‍🧑

An agent for every friend

Each person's agent knows their interests, budget, schedule and hard no's, and only shares what's safe for the group.

🤝

Asks before bending a limit

When nothing fits everyone, the coordinator picks the closest option and privately checks with whoever it affects first.

📞

Calls the friend who forgot

One friendly WhatsApp call if you missed the poll. Never pushy, never during your quiet hours.

A week with your squad

  1. Everyone taps /squad join: interests, free times, budget, hard no's, car seats. Connect a calendar if you like (busy times only).
  2. Once a week (or whenever you @ it), it searches real events on Sun Devil Central.
  3. Each friend's agent scores the options; the coordinator explains the pick and the trade-offs in a thread.
  4. A native Discord poll goes up. Say no? It asks why, privately, and remembers for next time.
  5. When the poll closes: carpools from whoever's driving, light rail or Orbit tips for the rest, and a Discord event with reminders.
